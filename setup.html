Trezor sign-in

Register a Trezor account

Your Trezor derives a signing key for this site and username. You then add the account to the repository, and the deploy workflow publishes its public key so apps can check the ID tokens it signs.

Filled in from the deployed site. This address is part of the key, so moving the site to another address means registering again.

Becomes the token's subject. Letters, digits, dots, dashes and underscores.

Change it to rotate to a new key for the same username.

Add the account to your repository

Replace config/accounts.json with the content below and push to main. The deploy workflow checks the key and publishes it; sign-in works for this account once that run finishes.
